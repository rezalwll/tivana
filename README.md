# گالری طلای تیوانا

وب‌سایت کاتالوگ و ثبت درخواست خرید گالری تیوانا با Next.js. این پروژه عمداً پنل مدیریت، حساب کاربری و درگاه پرداخت ندارد؛ محصولات در `data/products.ts` مدیریت می‌شوند و درخواست خرید از طریق قابلیت Share مرورگر آماده می‌شود.

## اجرا

```bash
npm ci
npm run dev
```

بررسی نسخهٔ نهایی:

```bash
npm run lint
npm run typecheck
npm run build
```

پس از ورود اطلاعات واقعی، گیت کامل انتشار را اجرا کنید:

```bash
npm run release:verify
```

این دستور هیچ انتشار یا دیپلویی انجام نمی‌دهد؛ دامنه، راه تماس، تأیید کاتالوگ و سیاست‌های تجاری را کنترل می‌کند و سپس lint، TypeScript، build و audit وابستگی‌های اجرایی را اجرا می‌کند.

## پیش از انتشار

1. فایل `.env.local` را از روی `.env.example` بسازید و `NEXT_PUBLIC_SITE_URL` را با دامنهٔ واقعی جایگزین کنید.
2. قیمت، وزن، موجودی و شرایط تجاری محصولات را در `data/products.ts` با اطلاعات واقعی گالری تطبیق دهید.
3. شماره، واتساپ، اینستاگرام، ایمیل و شهر رسمی گالری را در `.env.local` وارد کنید. فوتر، صفحه تماس و ارسال درخواست واتساپ به‌صورت خودکار از همین تنظیمات استفاده می‌کنند.
4. شرایط ارسال، تعویض و فاکتور را با رویهٔ واقعی کسب‌وکار تطبیق دهید.
5. پس از بازبینی نهایی محصولات و سیاست‌ها، گزینه‌های `TIVANA_CATALOG_CONFIRMED` و `TIVANA_POLICIES_CONFIRMED` را در `.env.local` روی `true` قرار دهید.
6. هر محصول بهتر است تصویر واقعی خودش را داشته باشد. فقط اگر استفاده چند محصول از یک تصویر آگاهانه و صحیح است، `TIVANA_SHARED_PRODUCT_IMAGES_CONFIRMED=true` را ثبت کنید.

مقادیر تماس قدیمی موجود در تاریخچهٔ پروژه (از جمله `09210000000`، `@tajgallery` و آدرس‌های نمونهٔ تهران) ساختگی بوده‌اند و نباید دوباره استفاده شوند.

انتشار در این مخزن انجام نشده است.
